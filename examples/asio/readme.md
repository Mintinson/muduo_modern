* 服务端程序在某个端口侦听（listen）新的连接。
* 客户端向服务端发起连接。
* 连接建立之后，客户端随时准备接收服务端的消息并在屏幕上显示出来。
* 客户端接受键盘输入，以回车为界，把消息发送给服务端。
* 服务端接收到消息之后，依次发送给每个连接到它的客户端；原来发送消息的客户端进程也会收到这条消息。
* 一个服务端进程可以同时服务多个客户端进程。当有消息到达服务端后，每个客户端进程都会收到同一条消息，服务端广播发送消息的顺序是任意的，不一定哪个客户端会先收到这条消息。

server 的实现有所不同：
* `chat_server`: 最简单的首 chat_server 实现
* `server_threaded`：使用多线程TcpServer，并用mutex来保护共享数据。
* `server_threaded_cow`： 对共享数据以借shared_ptr实现copy-on-write”的手法来降低锁竞争。
* `server_thread_local`:  采用thread local变量，实现多线程高效转发。
